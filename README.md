# Speed Curve

`실행.cmd`를 더블클릭하면 브라우저에서 열립니다. 영상은 이 PC의 FFmpeg로 처리하며 인터넷 업로드나 별도 서비스 결제가 없습니다. 현재 PC에 설치된 Python과 FFmpeg를 사용합니다.

1. 영상을 드래그하거나 파일을 선택합니다.
2. 시작·끝 배속(0.1~8배)을 입력합니다.
3. Ease In / Ease Out / Ease In Out을 고릅니다.
4. 속도 미리보기로 확인한 뒤 MP4 내보내기 → 저장을 누릅니다.

Ease In은 변화가 후반에 집중되고, Ease Out은 초반에 집중됩니다. Ease In Out은 양끝에서 부드럽게 변합니다. 끝 배속이 시작보다 낮으면 같은 곡선을 따라 감속합니다. 두 배속이 같으면 일정 속도입니다. 곡선의 가로축은 원본 영상의 진행률입니다.

오디오 유지를 켜면 음높이를 유지하며 함께 변속합니다. 끄면 무음 MP4로 출력합니다. 원본 오디오 트랙이 없으면 이 옵션을 사용할 수 없습니다. 브라우저에서 원본 형식이 재생되지 않아도 FFmpeg가 지원하는 영상은 MP4 내보내기가 가능합니다.

출력은 H.264/AAC MP4입니다. 원본 크기를 유지하되 H.264를 위해 홀수 크기는 가장 가까운 작은 짝수로 맞추고 최대 60fps로 저장합니다. 감속 프레임은 반복하며 광학 흐름 보간을 추가하지 않습니다. 결과 길이는 프레임 단위 반올림 때문에 예상값과 최대 약 한 프레임 차이가 날 수 있습니다.

업로드 원본의 로컬 복사본과 결과는 `data/`에 보관됩니다. 서버가 꺼진 상태에서 필요 없는 작업 폴더를 지울 수 있습니다. 원래 선택한 원본 파일은 수정하지 않습니다. 다른 PC에서는 Python 3.10 이상과 FFmpeg/ffprobe가 PATH에 있어야 합니다.

개발 실행: `python server.py --port 8765`

검증: `python test_engine.py` 및 `python test_audio_sync.py`

## 구현 참고

영상은 세 가지 이차 이징의 역배속 적분을 해석식으로 계산해 FFmpeg setpts에 적용합니다. 오디오는 40ms 간격의 tempo 명령을 Rubber Band 필터에 전달합니다(긴 영상에서는 최대 약 4,000회로 간격을 조정). 현재 PC의 FFmpeg에 해당 필터가 포함되어 있습니다. 다른 PC에서도 오디오 변속에는 librubberband가 포함된 FFmpeg가 필요합니다. 피치는 보존하며 극단적 배속에서는 시간 신축 특성상 음질이 달라질 수 있습니다.

공식 FFmpeg 필터 문서: https://ffmpeg.org/ffmpeg-filters.html
